# VRchat-LocalCinema

> 面向 VRChat 观影场景的 Windows 本地视频媒体库与 HTTP 分享工具：导入视频、检测格式兼容性、必要时一键转码，再把链接交给支持 HTTP 视频播放的播放器；也可通过内置 EasyTier 与朋友组建虚拟局域网，互相共享媒体库。

## 特性

| 能力 | 说明 |
|------|------|
| 媒体库 | 拖放导入视频文件与文件夹并保留目录层级；类文件资源管理器网格浏览，支持多级文件夹与「返回上一级」；自动记录标题、时长和封面信息 |
| 格式检测 | 使用 FFprobe 按白名单严格检测容器、编码、位深、像素格式与音频参数；不兼容的文件标记「不支持」并显示原因 |
| 转码 | 一键转码为 H.264 + AAC MP4；分段转码让第一段快速可用；独立转码任务队列，串行执行、进度可视 |
| HTTP 分享 | 默认端口 `17001`，支持 GET、HEAD、Content-Length、Content-Type 和 Range 分段请求，媒体按流读取，不把整部视频载入内存 |
| 虚拟局域网联机 | 内置 EasyTier：按房间名和密码组建房间，成员列表实时显示直连/中转、延迟与丢包；按文件哈希发现其他成员的共享视频并直接下载 |
| 地址生成 | 本地地址使用 `127.0.0.1`；局域网模式自动枚举本机 IPv4 地址并生成链接 |
| 播放器 | 检测 VLC、PotPlayer、mpv、MPC 等外部播放器，也可以手动选择播放器和启动参数 |
| 安全路由 | 通过媒体库登记记录访问文件，不直接暴露文件系统路径，并拦截路径遍历请求 |
| 便携使用 | 提供 base（不含 ffmpeg 与 easytier-cli）与 full（内置组件）两种包；识别程序目录下的 `portable.dat` 或 `data/`，数据可随程序目录携带、备份和升级 |
| 托盘与启动 | 可设置关闭窗口时退出程序或隐藏到托盘，也可设置开机启动 |

> HTTP 访问不会改动原视频，源文件始终留在原位置。某个文件能否被 VRChat 播放，取决于其容器与编码组合：程序会按白名单标记兼容性结果，不支持的文件可一键转码为 H.264 + AAC MP4 后再分享。

## 快速开始

我是小白，完全不懂github，看这里→[小白请读我](https://github.com/FlandreSatori/VRchat-LocalCinema/blob/main/%E5%B0%8F%E7%99%BD%E8%AF%B7%E8%AF%BB%E6%88%91.md)

### 使用发布版

1. 下载 release，二选一：**base 包**未内置 ffmpeg 与 easytier-cli（缺少组件时程序会提示自动下载或手动配置），**full 包**内置两组件开箱即用。解压后运行 `VRchat-LocalCinema.exe`。
2. 在媒体库页面点击导入，或把视频文件拖进窗口。
3. 等待媒体信息和封面处理完成；没有 FFmpeg 时仍可管理和分享视频，只是可能没有自动封面或时长。
4. 点击视频的链接按钮：
   - **本地模式**：如果使用此链接，房间内的每个玩家都需要运行本程序，并提前下载好相同的视频文件。
   - **局域网模式**：如果使用此链接，房间内的每个玩家都需要运行本程序，并在「EasyTier」页面加入相同房间名和密码的房间组建虚拟局域网。
5. 将链接粘贴到支持 HTTP 视频播放的播放器中（如浏览器），测试无误后可进 VRchat 播放。

默认地址形如：

```text
http://127.0.0.1:17001/视频文件名.mp4
```

## 配置

设置页面提供以下选项：

| 设置 | 默认值 | 说明 |
|------|--------|------|
| 监听模式 | 本地模式 | 本地模式监听 `127.0.0.1`；局域网模式监听 `0.0.0.0` |
| HTTP 端口 | `17001` | 可改为其他未被占用的 `1-65535` 端口，**需要保持所有人的端口相同** |
| 默认链接模式 | 本地模式 | 决定生成链接时优先使用本地地址还是自动检测到的局域网 IPv4 |
| 外部播放器 | 跟随系统默认 | 可选择播放器可执行文件，并设置 `{path}` 参数模板 |
| FFmpeg / FFprobe | 自动查找 | 可留空，程序会依次查找内置目录和系统 `PATH`；缺失时可一键下载最新组件或打开官方下载页 |
| easytier-core / easytier-cli | 自动查找 | 可留空，程序会依次查找内置目录和系统 `PATH`；缺失时可一键下载最新组件或打开官方发布页 |
| 封面目录 | 数据目录下的 `thumbnails/` | 可指定封面缓存目录 |
| 开机启动 | 关闭 | 根据 Windows 启动项运行 |
| 关闭行为 | 退出程序 | 也可以选择隐藏到系统托盘 |

FFmpeg 是可选的外部程序，用于提取封面和时长，不随本项目保证提供。WebView2 是桌面窗口运行所需的 Windows WebView 运行时；Windows 11 通常已内置，缺少时请按系统提示安装。

导入只会把文件登记到媒体库并读取元数据，原视频文件仍在原位置。两个登记文件出现不区分大小写的同名时，程序会拒绝新的冲突条目，原文件不会被覆盖、移动、重命名或删除。

## 数据目录

程序有两种数据位置：

| 模式 | 判定 | 数据位置 |
|------|------|----------|
| 便携模式 | 程序目录存在 `portable.dat` 或 `data/` | `程序目录/data/` |
| 常规模式 | 不满足便携模式条件 | `%APPDATA%\VRchat-LocalCinema\` |

目录内容：

```text
data/
├── library.db       # SQLite 媒体库记录
├── settings.json    # 监听、播放器、关闭行为等设置
├── thumbnails/      # 自动或手动封面缓存
├── converted/       # 转码产物（一键转码与分段转码）
└── logs/            # 应用日志
```

备份或升级便携版时，请先关闭程序，再完整复制 `data/` 目录。升级程序文件不会替换原视频；恢复备份时也建议同时保留原视频所在位置，否则媒体库会显示文件丢失。

## FAQ

### 为什么VRchat观影房间里输入 `127.0.0.1` 链接后只有房主本人能看到视频？

当玩家的电脑加载VRchat房间时，其内包含的播放器是运行在玩家自己的电脑上的。

因此当房主设置了播放连接为本地链接（比如`http://127.0.0.1:17001/test.mp4`）时，播放器会在自己电脑上寻找对应的视频并播放。

未安装本程序或未下载并拖入视频的玩家无法播放。

### 那能否让公网或异地朋友在不提前下载视频文件的时候直接观影？

可以。在「EasyTier」页面按相同房间名和密码组建虚拟局域网（full 包内置组件，base 包首次使用需下载或配置 easytier-cli），成员之间还会按文件哈希比对媒体库，可直接下载对方共享的视频。异地访问仍可能有不可避免的卡顿问题，取决于视频原文件所在机器的上传带宽。

### 为什么封面或时长为空？

封面和时长提取依赖可执行的 FFmpeg/FFprobe。安装后加入系统 `PATH`，或在设置中分别选择 `ffmpeg.exe` 和 `ffprobe.exe`，再刷新媒体信息。

### 修改了视频源文件后会发生什么？

媒体库保存的是登记时的文件路径和元数据。移动或重命名源文件会导致条目标记为丢失；重新导入前请处理旧条目。程序不会替你改动原文件。

### 同名文件可以同时导入吗？

不能。程序按不区分大小写的文件名检查冲突，会保留已有登记并拒绝新的同名条目；原文件不会被覆盖或改名。

### 关闭窗口后服务还在吗？

默认关闭行为是退出程序，退出前会停止 HTTP 服务。若选择“最小化到托盘”，关闭窗口只会隐藏界面，服务继续运行；可从托盘菜单显示窗口或退出程序。

### VRChat 播放不了某个视频怎么办？

程序会用 FFprobe 按白名单检测文件的容器、视频编码、位深、像素格式与音频参数；不在白名单内的文件会在媒体库标记「不支持」并显示具体原因。可在卡片右键菜单选择一键转码为 H.264 + AAC MP4，或使用分段转码先生成一段可播放的视频尽快开演。

## 源码构建

开发环境：

- Windows 10/11
- Node.js 22.12 或更高版本（当前 Vite 依赖要求；也支持 Node.js 20.19+）
- Rust 1.90 或更高版本，MSVC 工具链（以当前锁定依赖要求为准）
- Windows WebView2 Runtime

安装依赖并启动完整桌面应用：

```powershell
npm install
npx tauri dev
```

只预览前端界面：

```powershell
npm run dev
```

运行 Rust 测试：

```powershell
Set-Location src-tauri
cargo test
```

构建绿色便携版：

```powershell
Set-Location ..
powershell -File scripts\package-portable.ps1
```
